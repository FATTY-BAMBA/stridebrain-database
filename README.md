# StrideBrain Data Platform

Dedicated source repository for **future customer-facing** StrideBrain data architecture, migrations, policies and security acceptance tests.

**Current status: design and implementation staging only. No database is provisioned, no migration has been executed, and no real customer accounts or data have been created.**

The public, switchable industry demonstrations remain in the separate `primestride-web` feature branch. This repository is for the future authenticated, private per-organization system.

Changes to database schema, authorization policies or data processing require review, reproducible tests and an explicitly authorized deployment plan before reaching production.
